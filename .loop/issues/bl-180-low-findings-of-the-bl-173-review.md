## What

Low findings of the bl-173 review. Four are fixed, one is closed.

**Fix 1, a machine slot leak when the scope is cancelled.** In the orchestrator's merge sync, the machine slot of a merge wait is claimed before a `scope.async(start = CoroutineStart.LAZY)` job is created and started. If the scope is already cancelled when the job starts, its body and its `finally` never run, so the machine slot row and the `checking` entry stay until the pid liveness rule clears the row after the process exits. Desired: a cancelled scope never leaves a machine slot or a `checking` entry behind. Either the claim moves inside the job, or a job that never ran releases both (for example through `invokeOnCompletion`). The slot decision itself (when a slot is needed) does not change.

**Fix 2, two tests.** One asserts that a merge wait started in phase check under `ci: none` keeps its agent slot through the merge phase (`waits.checks` stays 1 until the merge ends). One covers a merge wait that starts in phase merge after `retrying()`.

**Fix 3, a docs sentence.** Since bl-173 the auto merge reviewer's model session runs with no agent slot, bounded only by the machine slot and the one head queue. Say in `docs/self-hosting.md` and in the m2-26 "Slot" paragraph that `agent.max_concurrent_agents` caps agent attempts and merge checks, not the auto merge reviewer.

**Fix 4, readability.** Split the "Slot" paragraph of m2-26 in `docs/spec-decisions.md` into short paragraphs, and make its first sentence state the rule as it is since bl-173 (the check holds an agent slot, the merge phase does not), instead of an unconditional sentence qualified later.

**Closed, a moved base in phase merge.** A run started in phase merge that finds a moved base stops at phase check of the new round and rechecks at the next tick. This is the spec decision of bl-173, not a defect. Nothing to change.

Area: the merge sync and the slot decision (`Orchestrator.kt`, grep, never read it whole), `Merges.kt`, `docs/spec-decisions.md`, `docs/self-hosting.md`.

Out of scope: changing which phases hold an agent slot, any change to the machine cap, the moved base behavior above.
