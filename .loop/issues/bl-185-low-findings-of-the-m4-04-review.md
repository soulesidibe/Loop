## What

Low findings of the m4-04 review. Triage decides which are worth fixing.

1. **`budgetWins` relabels a succeeded end.** In `Orchestrator.kt` `runAttempt`, after `endSession`, a budget breach from usage read at the attempt end stop turns any result into a budget park, unless it parks or waits for approval. For a successful handoff, or a `terminal`, `not_active` or `not_found` end (the issue left the active states), the attempt is recorded as `failed` with reason `budget`, the `exit_reason` is dropped from `attempt_finished`, and a park record is written on an issue in review or done. For a `terminal` end no continuation retry is scheduled, so `onTerminalRetryDropped` never removes the workspace (it stays until the startup cleanup). No work is lost. Suggested fix: also exempt succeeded ends where the issue left the active states.
2. **The override drops `runner_unavailable`.** A `runner_unavailable` failure relabelled as a budget park loses its `unavailable` flag, so no runner hold starts. Wake requests queued after the last drain are dropped instead of applied at close (`closingOf` drains only on success).
3. **A failing usage callback reads as a stop failure.** In `ClaudeCodeRunner.kt` (around line 302) with `StopUsage.kt` (around line 28), an exception thrown by the orchestrator's usage callback during `reports.forEach { report(it) }` is caught as a stop failure, so `session_stop_failed` is recorded although the process group was released. Already true at a rotation since bl-132, new at the attempt end.
4. **The cost of a partial wake is not counted.** `graceExpired` in `ClaudeCodeRunner.kt` counts tokens from the wake's assistant lines only; those lines carry no cost, so dollar budgets undercount when the grace expires during a wake.
5. **No `stop` ledger line without a turn line.** `StopUsage.line` returns null when no turn line was written, so the usage read at such a stop is in the attempt totals but in no ledger line. Unreachable with Claude Code today.
6. **Plugin API change.** `AgentSession.stop(usage)` became `stop(report)` in `plugin-api`, source incompatible for an outside runner that overrides it, with no deprecation.
7. **Nit.** `StopUsage.stop` repeats the `describe()` expression (`message ?: simpleName`) instead of calling it.

Area: `Orchestrator.kt` (grep, never read it whole), `StopUsage.kt`, `ClaudeCodeRunner.kt`, `plugin-api/.../AgentSession.kt`.
