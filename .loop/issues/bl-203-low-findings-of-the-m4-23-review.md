## What

Low findings of the m4-23 review. Triage decides which are worth fixing.

1. **The example sources check is a network oracle once workers are sandboxed.** `docs/examples/research/check-sources.sh` (around line 78) runs `curl -L` on agent chosen URLs, loopback, private ranges and 169.254.169.254 included, and a failed check's output goes back to the agent (`Orchestrator.kt`, around line 4103, `VerifyFindings.of`). Harmless under today's trust model; a confused deputy once M5 sandboxes workers (PLAN 11.2) while checks keep host network. Add a header and spec-decisions note, and revisit in M5.
2. **curl URL globbing is on.** No `-g` in `check-sources.sh` (around line 78), and the link grep (around line 70) does not exclude `[` or `{`, while the header (around line 17) says `[` ends a link. `http://host/[1-1000000]` fans one link out into many requests. Fails closed. Add `-g` and `--max-redirs 5`; `--max-filesize` too.
3. **No cap on the number of links or total time** in the script's loop. N links times 10 s can exceed the check's `timeout_ms`, giving unverified.
4. **Any final status from 200 to 399 counts as reachable**, so a 3xx without a Location header passes. Require 2xx.
5. **One reachable link is enough for the Sources section**, other sources may be plain text. Known limit, content review is M6.
6. **`require_sections` alone never refutes.** With no `checks`, the verdict is unverified "no check" and the section findings never reach the agent (`Orchestrator.kt`, around lines 3906 and 4056). Fail safe; add a loader refusal or a doc line.
7. **Required sections are satisfied falsely** by a heading inside an HTML comment, or by a zero width character as the only content (`RequiredSections.kt`, around line 17, `isNotBlank`). A report starting with a UTF-8 BOM fails its first heading.
8. **An oversize report records a truncated size and digest** (`DeliverableFiles.kt`, around line 127, `readNBytes(REPORT_MAX_BYTES + 1)`). Refuted anyway, but the evidence number is wrong.
9. **`verify.require_sections` is now refused on a kind without `deliverable.report`.** Stricter config; none in this repository.
10. **`./gradlew build` now needs `sh` and `curl`** on the build machine (`SourcesCheckExampleTest`).
11. **Test gaps:** a hanging server and the timeout path, a redirect to a bad target, a non http link, `policy: auto` on a report kind end to end, and an oversize report.

Area: `docs/examples/research/check-sources.sh`, `RequiredSections.kt`, `DeliverableFiles.kt`, `WorkflowFile.kt`, `VerifyFindings.kt`, `Orchestrator.kt` (grep, never read it whole).
