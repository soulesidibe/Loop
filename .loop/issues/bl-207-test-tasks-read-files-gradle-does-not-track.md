## Parent

None. Backlog, not scheduled in a milestone. Found on 2026-11-25 while checking the CI speedup of pull request #40 (sharding, CDS, arm runners) for tests the cache or the shards could hide. The shards are clean: on cc7cf8a, one unsharded `:cli:test` ran 639 tests and the 4 shards ran 639, no duplicates, none missing, all passing. The two gaps below predate pull request #40: `org.gradle.caching=true` and the CI Gradle cache are in the first public commit.

## What

1. **`:conformance:test` never reruns when `docs/spec-decisions.md` or a test it names changes.** `ConformanceMatrixTest` finds the repository root from `user.dir` and reads `docs/spec-decisions.md`, then every `.kt` test file the doc names, in any module (`ConformanceMatrix.check`). None of them is an input of the task. Reproduced on cc7cf8a: with a link to a missing test appended to the doc, `./gradlew :conformance:test` reported `UP-TO-DATE` and passed, and `./gradlew :conformance:test --rerun` failed in `the current matrix names only paths and tests that exist()`. The doc changed in 34 commits since 2026-11-24, so the guard can be skipped silently in CI, from cache on main and on branches.
2. **`:spec-core:test` never reruns when a GitHub recording changes.** `CiWaitOrchestratorTest` reads `plugins/tracker-github/src/test/resources/github/recorded` by a relative path (`RECORDED`, around line 994). `:cli:test` declares that folder as the `githubRecorded` input, `:spec-core:test` does not. Found by reading, not reproduced.

Suggested fix, build files only: in `conformance/build.gradle.kts`, declare `docs/spec-decisions.md` and the test source folders the doc can name (the `src/test` folders of all modules, path sensitivity relative) as inputs of `tasks.test`; in `spec-core/build.gradle.kts`, declare the recorded folder as an input, as `cli/build.gradle.kts` does. Passing the paths as system properties instead of `user.dir` and `../` would make the dependency explicit; triage decides.

## Agent Brief

**Category:** bug
**Summary:** declare as Gradle test inputs the repository files that :conformance:test, :spec-core:test and :cli:test read, so the build cache cannot skip them when those files change.

**Current behavior:** :conformance:test reports UP-TO-DATE or FROM-CACHE after docs/spec-decisions.md or a test file it names changes, so a broken conformance matrix passes from cache (reproduced on cc7cf8a). :spec-core:test does the same when a file under plugins/tracker-github/src/test/resources/github/recorded changes. :cli:test does the same when docs/plugins/, docs/examples/research/check-sources.sh, spec-core/src/test/resources/prompt/own-template.md or the root .gitignore changes.

**Desired behavior:** decided, build files only, no test change.
- conformance/build.gradle.kts: `tasks.test` declares docs/spec-decisions.md as an input file, and the `src/test` folders of every module (root modules and plugins/*) as an input file tree, path sensitivity relative.
- spec-core/build.gradle.kts: `tasks.test` declares the recorded folder as an input directory, path sensitivity relative, the way cli/build.gradle.kts declares `githubRecorded`.
- cli/build.gradle.kts: `tasks.test` adds inputs, path sensitivity relative: docs/plugins/ and docs/examples/research/ as directories, spec-core/src/test/resources/prompt/own-template.md and the root .gitignore as files.
- The tests keep their current path lookup (`user.dir`, `../`, the `loop.rootWorkflow` parent).

**Key interfaces:** conformance/build.gradle.kts, spec-core/build.gradle.kts, cli/build.gradle.kts. For reference only: ConformanceMatrixTest.kt, ConformanceMatrix.kt, CiWaitOrchestratorTest.kt, spec-core reactions `*ReactionTest.kt`, PluginProfileDocsTest.kt, SourcesCheckExampleTest.kt, ResearchKindRunTest.kt, OwnWorkflowTest.kt.

## Acceptance criteria

- [ ] `./gradlew build` passes.
- [ ] After a cached `./gradlew :conformance:test`, a change to docs/spec-decisions.md alone makes the task run again (not UP-TO-DATE or FROM-CACHE); the PR shows the command and its task outcome.
- [ ] After a cached `./gradlew :conformance:test`, a change to a test file under any module's `src/test` alone makes the task run again; the PR shows the command and its outcome.
- [ ] After a cached `./gradlew :spec-core:test`, a change to a file under plugins/tracker-github/src/test/resources/github/recorded alone makes the task run again; the PR shows the command and its outcome.
- [ ] After a cached `./gradlew :cli:test`, a change to a file under docs/plugins/ alone makes the task run again, and the same holds for docs/examples/research/check-sources.sh, spec-core/src/test/resources/prompt/own-template.md and the root .gitignore; the PR shows at least the docs/plugins/ case.
- [ ] A second run with no file changed still reports the three tasks UP-TO-DATE.
- [ ] A grep of the test sources for `user.dir`, `../` paths and `System.getProperty` reads, quoted in the PR, shows no other test task reading a repository file outside its declared inputs.
