4. **A kind template edit alone does not reload**, since reload is keyed on the `WORKFLOW.md` hash; preflight reads the new file each tick while attempts render the old text (`Orchestrator.kt`, around line 1283). Documented.
5. **A template file that breaks with `WORKFLOW.md` unchanged stalls dispatch** with a preflight event and log each tick, but no `config_reload_failed` (`Orchestrator.kt`, around line 1290).
6. **A kind template inside the repository is not protected by default.** The docs example `.loop/templates/content.md` is not covered by `guards.protect` unless listed, so an agent's merged pull request could change a future prompt after a reload. Document it, or warn in preflight.
7. **The `issue.description` warning checks only the body** (`RunCommand.kt`, around line 132), so a kind template that omits it gets no warning; and when every kind has its own template, the body is no longer checked by preflight (`Preflight.kt`, around lines 114 to 124).
