## What

On a public repository anyone with a GitHub account can comment on any issue, and the author of an issue can edit its body at any time. Loop puts both in the prompt of an agent that runs commands and pushes branches.

- **Comments.** `GitHubTracker.completeIssue` (`plugins/tracker-github/src/main/kotlin/loop/tracker/github/GitHubTracker.kt`, around line 100) appends every comment of the issue under `## Comments`, whoever wrote it. The `required_labels` gate stops a stranger from starting an attempt, but not from adding text to an attempt a maintainer started.
- **Body.** `normalize` (around line 326) takes the body as is. A maintainer can label a stranger's issue `ready-for-agent` after reading it, and the stranger can then rewrite the body before the next poll.

The GitHub API gives each issue and each comment an `author_association` (`OWNER`, `MEMBER`, `COLLABORATOR`, `CONTRIBUTOR`, `FIRST_TIME_CONTRIBUTOR`, `FIRST_TIMER`, `NONE`, ...). The recorded fixture `issue-comments-26.json` already holds four comments with `NONE`.

Proposed shape, to settle in triage:

- A `tracker.provider.trusted_associations` list, default `[OWNER, MEMBER, COLLABORATOR]`.
- Comments from other associations are left out of `## Comments`, with one line saying how many were left out, so the agent knows they exist without reading them. Loop's own comments are written with the configured token, so they stay in.
- An issue whose author is outside the list is not a candidate: it is skipped with a `candidate_skipped` reason (for example `untrusted_author`), visible in `loop trace`, even when it carries the required labels. A maintainer who wants it worked copies it into an issue of their own.
- The docs page `docs/plugins/tracker-github.md` says what is trusted and why.

## Acceptance criteria

- [ ] Comments whose `author_association` is outside `trusted_associations` never reach the description, tested on the recorded `issue-comments-26.json` (all `NONE`) and on a mixed fixture.
- [ ] The description says how many comments were left out, and nothing of their text or author.
- [ ] An issue authored outside `trusted_associations` is skipped with a `candidate_skipped` reason, even with `ready-for-agent`, and `loop trace` shows the reason.
- [ ] The default list is `OWNER`, `MEMBER`, `COLLABORATOR`, and a workflow can widen or narrow it; an unknown value is a config error at load.
- [ ] `docs/plugins/tracker-github.md` documents the setting and the risk it closes.
- [ ] `./gradlew --no-daemon build` passes.
