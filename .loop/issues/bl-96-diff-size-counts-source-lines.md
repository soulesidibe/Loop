## Parent

None. Backlog, not scheduled in a milestone. Found in the Loop run review of 2026-11-16.

## What

8 of 12 Loop mode fallbacks were `diff_size` (1,318 to 3,995 lines). The merge-risk reviews counted only 505 to 864 changed source lines in those PRs; the rest were tests and docs. When `diff_size` fails, the gate skips the risk reviewer entirely (`Merge risk: not assessed, a condition failed`), so every large PR fell to a human with no assessment.

Directions for triage: count non test, non doc lines against `max_diff_lines` (or two limits); run the reviewer even when a hard condition fails, so the approval comment carries a band.

## Acceptance criteria

- [ ] `./gradlew --no-daemon build` passes.
- [ ] The auto merge `diff_size` condition counts non test, non doc lines against `max_diff_lines`, or uses two limits. A gate test with a diff that is large only in tests and docs shows it passes the condition.
- [ ] A result that fails a hard condition such as `diff_size` still gets a merge risk review, and the approval comment carries a band.
- [ ] Each copied finding that touches the diff size or reviewer path is handled; every other one is closed here with a one line reason or filed as a `bl-<nn>`.
