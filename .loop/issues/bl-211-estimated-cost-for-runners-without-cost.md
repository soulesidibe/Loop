None. Backlog, not scheduled in a milestone.

## What

The `codex-app-server` and `acp` runners declare `cost: false`: neither agent reports a dollar amount, so the ledger records no cost and every `budgets.*_usd` budget spends nothing for them. Only token budgets hold.

Both report token counts by kind (input, cached input, cache write, output). A price table per model, shipped by Loop and overridable in the workflow like `context.windows`, would give an estimated cost. Triage decides:

- whether an estimate may count against `budgets.*_usd`, or only show in `loop trace` and `loop status`;
- how the ledger marks an estimated cost apart from a reported one;
- what a model missing from the table does (no cost and a once per run warning, as `context.windows` does).

Note: on a subscription login (ChatGPT, Google login) the estimate is an API price equivalent, not money spent.
