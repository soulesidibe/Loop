## Agent brief

**Category:** bug

**Summary:** A GitHub request cannot hang on a stalled body, an `api_url` with credentials in it is refused, and a rate limit hold cannot last longer than GitHub's own window.

**Current behavior:**
- The JDK transport bounds a request until the response headers arrive. A server that sends headers and then stalls while sending the body is waited on without limit, so a tracker read never returns and the tick stops.
- `tracker.provider.api_url` accepts an address with userinfo, such as `https://user:secret@host`. The address is printed in messages and in `toString`, so a secret typed there can reach a log.
- The hold after a rate limit answer trusts `retry-after` and `x-ratelimit-reset` as sent. A negative, zero or absurdly large value gives a hold that ends in the past or lasts for days.

**Desired behavior:**
- One request, headers and body together, fails with the transport's usual error (an `IOException`, which the client turns into `TrackerError.Unavailable`) when it has not finished within the transport timeout.
- An `api_url` with userinfo is refused at load as `invalid_tracker_config`, with a message that names the setting and never prints the userinfo.
- A hold never ends later than one hour after the answer that set it, and a `retry-after` that is not a positive number is ignored in favour of the next rule the client already has. The bound is one named constant.
- The GitHub adapter profile lists the three rules.

**Key interfaces:**
- `GitHubTransport` and `JdkGitHubTransport`, its `timeout`.
- `GitHubTrackerSettings` and its `api_url` reading, `GitHubConfigError.Invalid`.
- `GitHubClient` and the hold it keeps (as bl-50 leaves it), `TrackerError.RateLimited`.

**Out of scope:**
- Sharing the hold between the tracker and delivery, and the race on it (bl-50).
- The page cap, `Link` header parsing and priority labels.
- Recorded fixtures against a real repository (bl-40).

**Triage notes:**
- One hour is the longest hold. GitHub's primary limit resets every hour, and its secondary limits ask for minutes.
