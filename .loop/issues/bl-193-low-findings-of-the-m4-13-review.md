## What

Low findings of the m4-13 review. Triage decides which are worth fixing.

1. **A failing tracker holds every restored wait after a restart.** `restoreWaiting` is skipped while any tracker fails (`Orchestrator.kt`, around line 616), so after a restart the verify waits of every tracker, with `requeueBehindHead` and `resumeAfterRestart`, wait until all trackers answer in one tick. Multi tracker only; an error is logged each tick and nothing is lost.
2. **Tracker reads are serial with no timeout.** `TrackerPoll.byStates` and `readByIds` (`TrackerPoll.kt`, around line 106) call the trackers one after another, so a hanging extra tracker delays the primary's dispatch for that tick. Depends on the adapters' own HTTP timeouts.
3. **A reload that changes `tracker.id` makes the run idle silently.** `followWorkflow` applies any valid file and `WorkflowDiff.kt` has no tracker rule; `byStates` then finds no config entry for the old adapter id (`TrackerPoll.kt`, around line 143), `asked` is 0, `nothingAnswered` is false, nothing is logged. Running attempts, waits and due retries still work, only new candidates stop, and `forgetAbsent` resets the retry counters (`RetryQueue.kt`, around line 300). Suggested fix: warn for an adapter with no entry, or refuse a reload that changes `tracker.id`.
4. **Two test names say the opposite of their assertions.** `ExtraTrackersRunTest` and `TrackerRegistryTest` keep their m4-11 names (extra trackers "not polled yet"), kept for the `deleted_tests` guard.
5. **`LedgerSetup` KDoc is stale.** `plugin-api/src/main/kotlin/loop/api/Ledger.kt` (around line 19) still says the tracker kind; since m4-13 the ledger's `tracker` field is the tracker id (`default`), not the kind (`files`). No code reads the field yet (`loop report` is m4-38), and old and new rows differ in meaning only.
6. **A reload that removes an extra tracker stops its running attempts.** `RetryTarget.of` gets null from `trackerOf` (`RetryCoordinator.kt`, around line 754), so the attempts end as `not_active`, logged at info, workspace kept.

Area: `TrackerPoll.kt`, `Orchestrator.kt` (grep, never read it whole), `RetryCoordinator.kt`, `RetryQueue.kt`, `WorkflowDiff.kt`, `plugin-api/.../Ledger.kt`.
