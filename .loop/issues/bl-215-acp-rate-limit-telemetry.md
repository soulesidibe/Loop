## What

The `acp` runner maps rate limit errors (429, 503, 529, `rate_limit` codes) to `runner_unavailable`, but emits no `rate_limit` events, so `loop trace` shows no quota level for Gemini runs. ACP has no standard rate limit notification, so this waits on `agy`.

Check whether `agy acp` sends a quota or rate limit notification or an extension field (in `usage_update`, `session/prompt` responses or a custom method). If it does, map it to the `rate_limit` event the Codex runner emits. If not, keep this issue as a watch item for later `agy` releases.
