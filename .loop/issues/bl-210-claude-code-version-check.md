## What

The Codex runner fails a start on another major version than the pinned one, and the `acp` runner under `preset: agy` checks `agy` is on major version 1 in its preflight. The Claude Code runner checks no version, so a Claude Code release that changes the stream JSON format is found only when a run misreads it.

Add a startup check: run `<command> --version`, record the version, and fail startup when it is not on the pinned major version, as the Codex and agy checks do. An unreadable version output is a warning, not a failure. Write the pinned version in `docs/spec-decisions.md` next to the Codex one.

## Acceptance criteria

- [ ] The machine checks section of `docs/plugins/runner-claude-code.md` states the pinned version and the behavior.
