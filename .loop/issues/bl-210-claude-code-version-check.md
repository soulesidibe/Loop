## What

The Codex runner fails a start on another major version than the pinned one, and the `acp` runner under `preset: agy` checks `agy` is on major version 1 in its preflight. The Claude Code runner checks no version, so a Claude Code release that changes the stream JSON format is found only when a run misreads it.

Add a startup check: run `<command> --version`, record the version, and fail or warn (triage decides) when it is not on the pinned major version. Write the pinned version in `docs/spec-decisions.md` next to the Codex one.

## Acceptance criteria

- [ ] `./gradlew :plugins:runner-claude-code:test` passes, with tests for a matching version, another major version and an unreadable version output.
- [ ] `loop run` reports a Claude Code version outside the pinned major at startup.
- [ ] The machine checks section of `docs/plugins/runner-claude-code.md` states the pinned version and the behavior.
