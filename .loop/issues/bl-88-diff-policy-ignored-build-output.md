## What

`diff_policy` counts git ignored files (`added and ignored <path>`) against `guards.protect`. On Loop's own repository, a build writes ignored files under protected globs, so results were refuted that no agent could fix:

- Protecting `build-logic/` whole refuted every result whose build ran: `build-logic/build/` and `build-logic/.gradle/` (943 paths on m3-15's first verification).
- `**/*.gradle.kts` matched the copies Gradle's kotlin-dsl writes under `build-logic/build/kotlin-dsl/plugins-blocks/extracted/`.

The order makes it worse: the kind runs `diff_policy` before `./gradlew --no-daemon build`, the build check recreates the files, and the merge check reruns `diff_policy` in the same workspace and refutes them. m3-15 was verified twice and refuted at the merge check twice for this alone; the agent finally moved it to `needs_info`.

Loop's own `WORKFLOW.md` works around it by protecting `build-logic/src/` and listing the build scripts by depth (`*.gradle.kts`, `*/*.gradle.kts`, `plugins/*/*.gradle.kts`, m3-01). Any other project whose build writes ignored files under a protected glob (a `build/` folder inside a protected tree, generated sources) hits the same wall.

Ignored files are counted on purpose: `docs/spec-decisions.md` (deny guards, what git would hide) treats an ignored file as a way to slip a change past git, for example a protected script replaced by an ignored copy. So the fix is not simply "skip ignored files".

Possible directions for triage:

- Count ignored files only when they were not there before the checks, or only when a tracked file of the same path exists at the merge base.
- Take the ignored file list once, before the first check of a verification, and have the merge check compare against the same snapshot instead of the workspace after the build.
- Let a kind declare build output roots (`guards.ignore_generated: [build/]`) that `diff_policy` skips when ignored.
- Run `diff_policy` again after the command checks in the verification too, so a verification and its merge check judge the same tree.
